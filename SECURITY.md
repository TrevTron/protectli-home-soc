# Security boundaries

This is a local reference lab, not an unattended managed security service. Only apply configuration and tests to systems you own or are authorized to administer.

The UDP receiver's source-IP filter does not authenticate the sender or guarantee delivery. Keep its HTTP dashboard and the analyst review UI on loopback. The model gets bounded facts and has no policy/tool control. Validation, raw-source hashes and note chains detect defined inconsistencies; they do not make a local administrator unable to rewrite the records.

Keep configuration exports, alias keys, original logs, endpoint context and archives private. Under the activated rolling policy, ordinary unpinned segments expire seven days after sealing or sooner under capacity pressure; the setup baseline and saved investigation records have separate preservation paths. Check [the retention guide](docs/RETENTION_ARCHIVAL_AND_OBSERVATION.md) and verify a private backup before maintenance. Same-disk rollback and archives do not establish full disaster recovery. Never expose the GUI, serial console, model API or review UI to WAN for this workflow.

For a suspected security issue, use Trevor's [public contact page](https://unland.dev/contact) to arrange a private report. Do not post raw evidence or credentials in a public issue. No response-time commitment or bug bounty is implied.
