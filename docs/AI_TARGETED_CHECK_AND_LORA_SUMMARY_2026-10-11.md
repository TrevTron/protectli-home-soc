# Targeted checks and small-model training: summary and release boundary

Reviewed October 11, 2026 against the retained phase-two requests, answers, runtime records, training steps, adapter bytes and authored case sources. This is a summary, not a portable public export of that experiment. The existing 219-request export stays unchanged.

The original comparison used 24 authored test cases. A fixed-priority code baseline selected useful actions and targets on 12/24; Qwen's simple procedure reached 14/24 and stronger procedure 16/24. The unchanged SmolLM2 base reached 9/24 and the first adapter 7/24 under the menu-restricted first-token metric. Base free generation produced zero valid choices within four new tokens; the first adapter produced 24 valid choices with seven useful ones. Format and routing quality are separate.

After the original results were exposed, a separate 24-case authored challenge was frozen. On those same fresh cases, the fixed code baseline reached 4/24, Qwen simple 19/24, Qwen stronger 21/24 and Qwen stronger with semantic action-and-target identifiers 22/24. The representation arm changed menu keys, output instruction and enum values together. It does not isolate a single wording change. The unchanged small base reached 4/24, the first adapter 6/24 and the continuation 11/24 under restricted-choice scoring. These are one draw per authored case and condition, not operational accuracy or human-benefit estimates.

The pinned base is [HuggingFaceTB/SmolLM2-360M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct/tree/a10cc1512eabd3dde888204e902eca88bddb4951). CPU BF16 and eight threads were used. Rank-eight q/v LoRA updated 819,200 float32 adapter parameters while base parameters remained frozen. The first fixed epoch completed 192 examples built around eight templates. The continuation used two new deterministic menu orders per original training case, 384 variants, and stopped at its declared time bound after 331 steps. These variants are not independent incidents. No production Qwen weight update or GPU training is claimed.
