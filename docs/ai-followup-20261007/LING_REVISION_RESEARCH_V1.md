# Ling revision research, 2026-10-07

The original harder-round Ling score remains 0/12. All twelve requests produced complete, input-verified responses. Every answer included an unsupported `compare_retained_window` check, so all twelve failed the strict check dimension. This was a decision-quality result, not twelve crashed or missing responses. The raw responses, grader and original seal remain unchanged.

The [official Ling 3.0 tiny model card](https://huggingface.co/inclusionAI/Ling-3.0-tiny) describes a reasoning-capable mixture of experts, with 7.9 billion total and 1.3 billion active parameters per token. Its recommended recipe enables thinking and uses temperature 1.0, top-p 0.95 and top-k 20. Our original run disabled thinking and used temperature zero. That difference is a testable hypothesis, not an established cause of the zero score.

The [official GGUF distribution](https://huggingface.co/inclusionAI/Ling-3.0-tiny-GGUF) and [merged llama.cpp support change](https://github.com/ggml-org/llama.cpp/pull/26608) support the existing native Bailing template path. The installed Q4_K_M weights and pinned CPU runtime remain the same. The GGUF's own template inserts its thinking option and assistant prefix. We preserve that template rather than substitute another family's format.

In a [first-person LocalLLaMA discussion](https://www.reddit.com/r/LocalLLaMA/comments/1w7y3sa/aa_update_heres_how_the_small_models_score/), users reported mixed experiences, including useful agent behavior, weaker non-thinking behavior, formatting problems and long reasoning. These are anecdotal observations across different setups. They motivate bounded testing but do not diagnose this local result or establish a winning configuration.

The inherited local system prompt also combined an earlier two-field contexts/checks contract with a later six-field investigation contract. The revised skill gives one consistent contract, explains exact receipt matching and scopes checks to unresolved evidence. That prompt revision is tested separately from reasoning and sampling changes.

Four predeclared development profiles isolate those factors: inherited prompt with thinking off; revised prompt with thinking off; revised prompt with greedy thinking; and revised prompt with the publisher's sampling recipe. All use a 4,096-token completion ceiling, 8,192-token context, one seed and identical development evidence. The initial reasoning cap was 1,024 tokens. All eight enabled-thinking traces reached it, so a separately sealed development extension tests both reasoning profiles with a 3,072-token cap. These bounded profiles are not unrestricted reproductions of the publisher's benchmarks. Raw reasoning and final channels are preserved separately; only the final six-field answer receives a quality grade.

The [pinned llama.cpp server documentation](https://raw.githubusercontent.com/ggml-org/llama.cpp/b11429/tools/server/README.md) documents native chat-template kwargs, separate reasoning content, JSON schema and reasoning budgets. The CPU child stays local and authenticated, with finite deadlines and owned-child cleanup. The ordinary analyst is restored after each batch. Existing collector, native monitoring, memory guards and host protections remain separate. No new host thermal certification is claimed.

Gemma's earlier 8/12 versus Qwen's 3/12 to 4/12 is an observed result for this particular contract and set of artifacts. [Gemma's official card](https://huggingface.co/google/gemma-4-12B-it) and [Qwen's official card](https://huggingface.co/Qwen/Qwen3.5-9B) describe different native sampling and reasoning recipes. We tested a common greedy, non-thinking recipe, different parameter counts and quantization. A fresh common-prompt comparison can clarify the task result; it cannot establish that one entire model family is superior.

The selected Ling profile is frozen using development scores before creating the new transfer pack. Fresh cases share known development families and are authored synthetic fixtures with private source-derived oracles. All five artifacts receive identical revised skill text, input evidence and answer schema. A separate selected Ling lane makes its reasoning/sampling difference explicit. Prior scores are not pooled with these new cases, and no answer is retried or repaired.
